## Sobre

Site profissional construído do zero com foco em **performance**, **design moderno** e **experiência do usuário premium**. Apresenta minha trajetória, projetos, stack técnica e informações de contato — sem frameworks, 100% vanilla.

## Stack do Portfólio

| Tecnologia | Uso |
|:---:|---|
| **HTML5** | Estrutura semântica, SEO, Open Graph, JSON-LD |
| **CSS3** | Design system com variáveis, glassmorphism, 15+ animações, tema claro/escuro |
| **JavaScript** | Intersection Observer, typing effect, parallax, tilt 3D, cursor glow |

## Features

- **Preloader** animado com branding
- **Tema claro/escuro** com persistência em localStorage
- **Cursor glow** que segue o mouse (desktop)
- **Typing effect** com roles rotativas
- **Contadores animados** com IntersectionObserver
- **Scroll reveal** em 5 variantes (fade, left, right, scale, rotate)
- **Parallax** nos glows de fundo
- **Tilt 3D** nos cards de projeto e skills
- **Staggered entrance** nas soft skills e skill cards
- **Shimmer text** no nome do hero
- **Scroll indicator** animado (mouse icon)
- **Mobile nav** com slide-in stagger
- **Favicon SVG** profissional
- **404 page** personalizada com terminal fake
- **JSON-LD** structured data para SEO
- **Open Graph** + Twitter Card com preview image
- **100% Responsivo** — mobile, tablet e desktop
