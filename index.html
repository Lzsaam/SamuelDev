Valorant Hub

Site temático full-stack com dashboard, ranking, quiz e mini jogo de treino de mira inspirado no universo de Valorant

Projeto individual desenvolvido na SPTech com front-end em HTML, CSS e JavaScript e back-end em Node.js com Express. O site apresenta o universo de Valorant com páginas dedicadas para agentes e mapas, sistema completo de login e cadastro, e uma dashboard interativa com gráficos usando Chart.js.

Inclui funcionalidades como ranking de jogadores, um quiz de perguntas sobre o jogo e um mini jogo de treino de mira. O front utiliza Swiper, Font Awesome e Boxicons para carrosséis e ícones, com persistência de dados em MySQL.

Projeto Principal

Desperdício Zero

Solução full-stack mobile + backend para controle de alimentos e redução de desperdício doméstico

Aplicação que permite cadastrar itens manualmente ou por leitura de código de barras, classifica automaticamente a urgência de consumo com base na data de validade, gera validade estimada quando o item não possui essa informação e mantém histórico de consumo, descarte e doação.

Implementei funcionalidades avançadas como notificações push automáticas, geração de receitas com IA usando Google Gemini, filtros e ordenação por prioridade, busca em tempo real, gestos de swipe e um painel de estatísticas com gráficos para análise do desperdício. Também estruturei um fluxo de ETL com Pandas para tratar dados do Open Food Facts.

  • Dashboard de estatísticas e impacto

Projeto Social

Inovare — ONG IMA

Sistema de agendamento e gestão de voluntários para a Instituição Mãos Amigas

Sistema completo para ONG que permite o cadastro de voluntários pelo administrador, disponibilização de horários de atendimento e cadastro de beneficiários com questionário social para classificação automática entre Benefício de Valor Social ou Programa Multidisciplinar.

IntelliSense

Plataforma de dados para combate à criminalidade e apoio à segurança pública em São Paulo

Sistema criado para auxiliar no combate à criminalidade em regiões do estado de São Paulo. A plataforma apoia o secretário de segurança na otimização de operações e gerenciamento de frotas, com dashboard que identifica áreas de risco para cidadãos.

Projeto Pessoal · IA

ClipGenius AI

Plataforma modular para automação do pipeline de corte e reaproveitamento de vídeos longos em clipes verticais prontos para distribuição

Converte qualquer vídeo (YouTube, Shorts, Reels públicos) em clipes verticais legendados prontos para publicar. Construído em 2 semanas como produto próprio, eliminando dependência de ferramentas pagas para criação de conteúdo para TikTok.

Arquitetura em camadas com domínio, aplicação e infraestrutura bem separados. Pipeline orquestrado com download resiliente via yt-dlp com cache, transcrição Whisper, análise multimodal (OpenCV + áudio + keywords + embeddings semânticos), scoring configurável e renderização em lote com ffmpeg em 9:16. Interface Streamlit "ClipGenius Studio" com presets, progresso em tempo real, feedback colaborativo e exportação de pacotes promocionais com CTA por plataforma.

Cobertura com 48 testes automatizados cobrindo pipeline, promoção, scoring, scripts e legendas. Motor de analytics com tracking de eventos, histórico de runs e ajuste automático de pesos.

Funcionalidades

  • Download resiliente + cache inteligente
  • Transcrição Whisper (GPU opcional)
  • Scoring multimodal + embeddings semânticos
  • Render em lote 9:16 com legendas
  • ClipGenius Studio (Streamlit) com presets
  • Pacotes promocionais .zip + CTA
  • 48 testes · Clean Architecture · SOLID
  • CLI completa com flags avançados
Python 3.13 Whisper OpenCV ffmpeg Streamlit yt-dlp PyTorch Pandas NLTK sentence-transformers
